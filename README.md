# Sprint_5: Автотесты для Stellar Burgers

Данный проект содержит автотесты для сервиса [Stellar Burgers](https://stellarburgers.nomoreparties.site/).  
Проверяется следующая функциональность:
- **Регистрация:** успешная регистрация (поле «Имя» не пустое, email соответствует формату login@домен, пароль – минимум 6 символов) и отображение ошибки при вводе некорректного пароля.
- **Вход:** вход через кнопку «Войти в аккаунт» на главной, через кнопку «Личный кабинет», через форму регистрации и через форму восстановления пароля.
- **Переходы:** переход в личный кабинет, из личного кабинета в конструктор (через кнопку «Конструктор» и по клику на логотип), а также проверка выхода через кнопку «Выйти».
- **Раздел «Конструктор»:** переходы к разделам «Булки», «Соусы», «Начинки».
